# .github

Organization defaults for Minimalisque. GitHub uses these files in every
Minimalisque repository that does not define its own:

- `.github/ISSUE_TEMPLATE/`: Feature, Task, and Bug issue forms (each sets
  its issue type); blank issues are disabled.
- `.github/pull_request_template.md`: the pull request description.

This repository is public because GitHub only reads organization defaults from
a public `.github` repository. It holds templates only; never add code,
configuration, or anything private here.
